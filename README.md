# JIIT Cafe Billing System ☕

This is my first C++ project.

## About
A simple cafe billing system where users can order food items, select quantities, and calculate their total bill.

## Features
- Displays the food menu.
- Takes item and quantity as input.
- Calculates the total bill.
- Provides a 10% discount on bills of ₹200 or more.

## Concepts Used
- C++ Basics
- Loops
- Switch Case
- If-Else Statements
- Variables and Arithmetic Operators
